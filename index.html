02 — Journey
My Story
2023 — Age 13
The Broken Arduino
Found an old Arduino board at a junk shop. Started watching tutorials at night. Didn't understand the code but loved the idea that you could make hardware do things with software.
2024 — Age 14
The ₹3,000 Robot
School science exhibition. No one else wanted to do robotics. I was the only one who knew anything. Led a team of 5 — none of them had experience. Bought ESP32, motors, motor driver, breadboard, wires. Budget: ₹3,000. Broke 4 ESP32s. Almost gave up. Then the 5th one worked — a web-controlled robot running on its own Wi-Fi.
2024 — Self-Taught
Learning to Solder
During the robot build, I taught myself to solder. Burned my fingers. Messed up joints. But eventually got clean connections. Also learned to use a multimeter, read resistor values, and debug circuits. All from YouTube and trial-and-error.
2025 — Python Era
Matrices Saved Me
Started learning Python on Khan Academy. In 10 days, went from zero to building a course recommendation engine using 2D arrays. Discovered matrices on my own while learning arrays. Built 5 iterations in 2 hours.
2025 — Now
The Hunger Grows
Built more robots. Ran self-experiments on learning. Juggling: 0 → 13 catches in 3 days, self-taught. Now looking for a team that matches my energy. Ready to build things that matter.
