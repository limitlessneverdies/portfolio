- **Projects** (`/projects`) — everything he has built: OFFQWEN, the Lifeline rescue contribution, the DeepAI bridge, token-radar-01, the Deepal showroom, Leonida Secrets, Rakshak, and more.

- **FAQ** (`/faq`) — the questions people actually ask, answered straight.

## Deploy

Cloudflare Pages project `bishowdeep`, **direct upload** (not Git-connected). Pushing here does not deploy. To deploy, upload this folder in the Cloudflare Pages dashboard — the folder pick is a human click in the browser.

## Tech

Static HTML/CSS/JS, no build step. Clean extensionless URLs. `sitemap.xml` lists all 16 pages; `robots.txt` points at the custom-domain sitemap.
